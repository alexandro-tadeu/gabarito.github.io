# Leitor de Gabarito PWA

Este pacote contém a versão PWA do Leitor de Gabarito por Foto.

## Arquivos

- index.html
- manifest.webmanifest
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

## Como hospedar

Hospede todos os arquivos em uma pasta pública usando HTTPS.

Sugestões:
- Netlify
- GitHub Pages
- Vercel
- Hostinger

## Como instalar no celular

### Android
1. Abra o link no Chrome.
2. Toque nos três pontinhos.
3. Escolha "Adicionar à tela inicial" ou "Instalar app".

### iPhone
1. Abra o link no Safari.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início".

## Observação importante

Para usar câmera no celular, hospede em HTTPS.


## Atualização da câmera

Esta versão inclui dois botões na aba Corrigir foto:

- Tirar foto no celular
- Escolher da galeria

No Android, o botão "Tirar foto no celular" deve abrir a câmera.
No iPhone, o Safari pode mostrar as opções de câmera, fototeca ou arquivos.

Importante: para câmera funcionar corretamente no celular, hospede com HTTPS.


## Versão com câmera melhorada

Esta versão melhora o uso no celular:

1. A foto tirada pela câmera é carregada em maior resolução.
2. O botão "Ler automático" continua disponível.
3. Foi adicionado o botão "Ler usando 4 cantos", recomendado para fotos tortas ou tiradas da folha inteira.

Como usar no celular:
- Tire a foto de perto, tentando enquadrar somente o quadro do GABARITO.
- Primeiro teste "Ler automático".
- Se não ler bem, toque nos 4 cantos da tabela e clique em "Ler usando 4 cantos".
