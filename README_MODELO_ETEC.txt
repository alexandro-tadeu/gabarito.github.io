LEITOR DE GABARITO PWA OPENCV - MODELO ETEC

Esta versão mantém o modelo visual mostrado pelo usuário:
- cabeçalho Etec / CPS / São Paulo;
- quadro de informações;
- instruções da atividade;
- título GABARITO;
- tabela com Questão / A / B / C / D / E;
- orientação para clicar nos 4 cantos da tabela.

Mudança principal:
A leitura OpenCV foi adaptada para a tabela do gabarito, sem depender de quadrados pretos nos cantos.

Como usar no celular:
1. Gere e imprima o cartão.
2. Tire a foto do cartão preenchido.
3. Toque nos 4 cantos externos da tabela do gabarito.
4. Clique em "Ler pelos 4 cantos da tabela".
5. Confira as respostas.
6. Aplique o gabarito oficial.

Observação:
O botão "Tentar detectar tabela automaticamente" existe, mas o modo recomendado é clicar nos 4 cantos.
